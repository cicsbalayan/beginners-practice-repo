4 STAGES IN GIT
•	Unstaged(Initializing stage)- git not initialized in folder/workspace being used
•	Working(modifying)- initialized, is working on the files
-can modify n track files during dev
•	Staged(to be uplouded)- done modifying, ready to put in cloud (github)
•	Committed (added to cloud)- in cloud (github)
